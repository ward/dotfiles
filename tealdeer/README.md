Find where to put each with

```sh
tldr --show-paths
```

Defaults at time of writing:

```
$ tldr --show-paths
Config dir:       /Users/ward/.config/tealdeer/ (OS convention)
Config path:      /Users/ward/.config/tealdeer/config.toml (OS convention)
Cache dir:        /Users/ward/.cache/tealdeer (OS convention)
Pages dir:        /Users/ward/.cache/tealdeer/tldr-pages/
Custom pages dir: /Users/ward/.local/share/tealdeer/pages/ (OS convention)
```

So just symlink config dir and custom pages dir to the folders in this folder.
